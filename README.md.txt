# Fortaleza de Itaipu Connect — 455º Grupo Escoteiro

Repositório unificado com os módulos desenvolvidos para o **455º Grupo Escoteiro Fortaleza de Itaipu (Praia Grande/SP)**.

## Estrutura do Repositório

- `site-institucional/`: Página web institucional de apresentação do grupo escoteiro (`index.html`).
- `ia-gefi/`: Módulo de inteligência artificial / assistente do grupo.
- `grupo-escoteiro/`: Arquivos e recursos do projeto web do grupo.
- `app-escoteiro/`: Aplicação mobile voltada aos membros e atividades escoteiras.
- `gestao-escoteira/`: Sistema de gestão administrativa e acompanhamento dos jovens.

## Como visualizar
- **Site institucional:** Abra o arquivo `site-institucional/index.html` diretamente no navegador.
- **Demais módulos:** Consulte os arquivos internos de cada diretório para instruções específicas de execução.
